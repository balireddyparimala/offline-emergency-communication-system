# Offline Emergency Communication System

## Project Overview

This project aims to develop an offline emergency communication system that enables people to exchange emergency messages without depending on the Internet or cellular mobile networks.

The system uses ESP32-based wireless communication nodes to transmit emergency information between nearby users.

## Problem Statement

During natural disasters, network failures, accidents, or other emergency situations, Internet and cellular communication may become unavailable. A reliable local communication system is therefore required to exchange important emergency messages within the affected area.

## Objectives

- Develop a communication system that works without Internet connectivity.
- Enable transmission of emergency messages between nearby users.
- Provide a simple and reliable emergency communication mechanism.
- Develop the system using low-cost and easily available hardware.
- Extend the system towards multi-node communication.

## Proposed Technology

- ESP32
- Wireless communication
- Embedded C/C++
- Arduino IDE
- Web-based user interface

## Project Development

The project will initially be developed as a two-node prototype and will later be extended to multiple nodes and multi-hop emergency communication.
